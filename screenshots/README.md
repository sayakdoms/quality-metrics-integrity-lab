# Screenshot checklist

Capture these images from the deployed v0.3.0 application at a common desktop
size, preferably 1440×900 or 1920×1080. Use only built-in hypothetical scenarios
or the repository's synthetic sample data. Do not include confidential,
user-provided, or personally identifiable data.

- [ ] `01-application-overview.png` — title, educational disclaimer, summary
  metrics, diagnostic, and readable scenario controls.
- [ ] `02-quality-mirage.png` — actual and reported paths, target reference,
  shaded reporting gap, labels, and interpretation.
- [ ] `03-scenario-comparison.png` — scenario selectors, B-minus-A summary,
  comparison chart, and visible interpretation.
- [ ] `04-spc-integrity.png` — actual and sanitised observations, control limits,
  legend, and signal summary.
- [ ] `05-cost-of-quality.png` — cost assumptions, comparison view, and the
  downstream-cost explanation.
- [ ] `06-metric-audit.png` — all audit questions, classification, and at least
  one recommendation.
- [ ] `07-csv-import-or-methodology.png` — validated synthetic CSV output or the
  academic-foundations section.

Before saving each image, confirm that there is no clipped text, overlap,
horizontal scrolling, open personal file picker, browser notification, or visible
local path. Crop consistently and keep the dark theme unchanged.
